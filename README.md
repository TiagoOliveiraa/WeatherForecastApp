# Weather Forecast App

## 🌤 About the Project
This is a **React** application built with **TypeScript** that provides detailed weather forecasts using the **OpenWeather API**. The app allows users to check the current weather, temperature fluctuations, and future forecasts for a requested location.

## 🚀 Features
- **Current Weather Information**: Displays the current temperature, including the **average, maximum, and minimum** temperatures for the day.
- **5-Day Forecast**: Provides a forecast for the next **four days** after the current day.
- **Temperature Unit Toggle**: Users can switch between **Celsius (°C) and Fahrenheit (°F)**.
- **Temperature Fluctuation Chart**: A graphical representation of **maximum and minimum** temperature variations over the next **5 days** using **Recharts**.
- **Temperature Map**: A **Google Maps API** integration with temperature overlays, zoomed into the requested city.

## 🛠 Technologies Used
- **React** with **TypeScript**
- **OpenWeather API** for fetching weather data
- **Styled-components** for styling
- **Recharts** for data visualization
- **Google Maps API** for the interactive temperature map
